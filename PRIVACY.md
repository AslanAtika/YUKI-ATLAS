# Public Publication Boundary

Publish approved original creative and technical material. Exclude real personal names, personal contact details, credentials, health narratives, private correspondence, local saves, and unrelated archives.

Use public handles for contributor credit. Do not publish private records merely because names have been scrambled; contextual details can still identify people.

Numbers used as game mechanics, Unicode code points, revisions, and fictional data are not personal contact numbers.

No private source records were imported for this update. This is not a certification of every linked site or future contribution, and no existing history was rewritten.

Commit metadata uses the account's public handle and GitHub-generated no-reply address, not a personal email address.
